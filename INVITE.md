# Creative System — приглашение на пилот

Привет! 👋

Хочу дать тебе на тест **Creative System** — инструмент для анализа Meta Ads креативов,
который мы делаем для себя и хотим валидировать на нескольких компаниях.

## Что это и зачем тебе

Платформа делает то, что обычно делается полу-вручную в Google Sheets, только автоматически
и системно:

- Подтягивает данные из **Meta Marketing API** (spend, CTR, impressions по каждому объявлению)
- Подтягивает лиды и оплаты (если есть BI типа Plurio/Elly — иначе CSV)
- Автоматически классифицирует объявления: **winner / fake_winner / loser / testing**
- **Ловит fake winners** — креативы, прошедшие KPI по CPL/CPQL, но проседающие
  внутри воронки или экономики. Это самая ценная фича — обычно их обнаруживается
  **в 3-10 раз больше** чем настоящих виннеров. Бюджет горит, KPI «зелёный».
- Делает **бивариативный анализ** — какие параметры (P/H/B/A) реально влияют на CPL,
  с причинно-следственной оценкой (HELPS / HURTS / NEUTRAL), а не просто корреляцией
- Генерит брифы и сценарии через Claude
- Шлёт алерты в Telegram (опционально)

## Сколько времени займёт установка

~1 час, если все ключи на руках. Без моего участия.

Установка автоматическая — через **Claude Code**. Ты не пишешь ни строчки кода:
открываешь файл-инструкцию, Claude проводит через 15 шагов:
- собирает ключи (Supabase, Anthropic, Meta)
- валидирует каждый через API
- генерит конфиг под твой бизнес
- применяет миграции БД
- деплоит на Vercel

В конце получаешь свой публичный URL вида `creative-system-xxx.vercel.app`
с твоими данными.

## Как стартовать

1. **Открой** https://github.com/sternmeisterde-ui/creative-system
2. **Нажми Fork** в правом верхнем углу — получишь свою копию репозитория
3. **Клонируй у себя локально:**
   ```bash
   git clone https://github.com/ТВОЙ_USER/creative-system.git
   cd creative-system
   ```
4. **Открой Claude Code** в этой папке (`claude` в терминале или через Desktop app)
5. **Скажи Claude'у:**
   > Прочти `INSTALL_WITH_CLAUDE.md` и проведи меня через установку шаг за шагом

Дальше Claude сам ведёт диалог: спрашивает Supabase URL, Anthropic key, Meta token,
рассказывает где их взять, валидирует каждый, спрашивает про твой бизнес,
генерит `brief.config.ts`, применяет миграции, деплоит.

## После установки

Открой свой задеплоенный URL → главное место — `/analytics`. Самые важные вкладки:
- **🟠 Fake winners** — где деньги горят втихую
- **⚖️ Бивариативный** — какие параметры реально работают, а какие маскируются под успех

Подкручивание порогов (CPL, CPQL, что считать fake winner и т.д.) — через
Supabase Studio → Table Editor → `app_settings`, правится строка `id=1` без передеплоя.

## FAQ кратко

**Сколько стоит?** Self-host = бесплатно. Платишь только за:
- Anthropic API (~$5-30/мес зависит от объёма анализа)
- Supabase (free до 500MB)
- Vercel (free до 100GB bandwidth)
- Meta API (бесплатно)

**Что с приватностью?** Все данные в **твоём** Supabase, не у меня. AI-промпты идут
напрямую в Anthropic (мы не видим). Anthropic не тренируется на данных API-клиентов.

**Без Plurio/Elly будет работать?** Частично. Meta-метрики (spend/CTR/impressions)
работают. Но без BI с лидами не считается CPL/CPQL → fake_winner detection не работает.
Альтернатива: грузишь CSV `ad_name → leads, qual_leads, spend, revenue` напрямую
в `pbi_metrics` через Supabase Studio.

**Английский UI есть?** Пока только русский.
