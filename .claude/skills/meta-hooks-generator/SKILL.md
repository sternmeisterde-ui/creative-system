# Meta Hooks Generator — генератор хуков для перфоманс-креативов

Скилл превращает исследование аудитории (персоны + JTBD) в готовые к тесту хуки для Meta Ads.
Хук = первые 1–3 секунды видео или первая строка статики/копирайта. Его единственная задача —
остановить скролл и купить следующие 2 секунды внимания. Хук НЕ продаёт продукт — он продаёт
досмотр.

**Метрика цели**: hook rate = 3-second video plays / impressions. Бенчмарки 2025–2026
(Motion, датасет $1.29B): <20% — пересобирать; 20–25% — база; 30%+ — цель; 40%+ — элита.
Reels судить на 5–10 п.п. ниже ленты. Статика: рычаг — первая строка primary text
(ядро в первых ~35 символах) + заголовок. Полные бенчмарки: [Часть III, §1](#1-бенчмарки-hook-rate).

## Структура файла

- **Воркфлоу** (ниже) — вход, 6 шагов процесса, формат выдачи, принципы качества
- **Часть I. JTBD → хуки** — методология: силы прогресса, job stories, язык клиента, стадии Шварца
- **Часть II. База психологических триггеров** — Канеман, Ариели, Чалдини, Лёвенштейн и др.
- **Часть III. Каталог паттернов 2024–2026** — бенчмарки, тактики, визуальные механики, анти-паттерны

Части I–III — рабочая база скилла. Используй все три слоя, а не выборочно: хорошие хуки
рождаются на пересечении «боль персоны × триггер × паттерн», без любого из слоёв получится генерик.

## Входные данные

Основной вход — файл (или таблица) с персонами и JTBD. Возможные источники:
- Файл, который дал пользователь (markdown, docx, json, таблица)
- `lib/seed-data.ts` — сид-персоны проекта (структура `Persona`: pains[], triggers[], pointA, pointB)
- Таблица `personas` в Supabase (через `/database` или API)

Из каждой персоны извлеки:
1. **Боли** (pains) — дословные формулировки, это готовый язык клиента
2. **Триггеры** (triggers) — что уже известно как работающее
3. **Точка А → Точка Б** (pointA/pointB) — материал для контраста и конкретики (цифры!)
4. **JTBD-силы**, если размечены: Push (что выталкивает), Pull (что притягивает),
   Anxiety (что тормозит), Habit (что держит на месте)
5. **Контекст сегмента**: flow COM (платят сами → выше тревожность, нужна ценность и риск-реверс)
   или GOV (Bildungsgutschein → государство платит, нужна простота и «это реально мне положено»)

Если пользователь не указал персону — спроси, под какую персону/flow генерировать,
или сгенерируй под каждую персону отдельным блоком.

## Процесс генерации

### Шаг 1. Разбор персоны
Выпиши для выбранной персоны: топ-3 боли (в формулировках клиента), топ-3 триггера,
контраст А→Б с цифрами, доминирующую JTBD-силу и стадию осознанности по Шварцу
(см. [Часть I, §5](#5-стадии-осознанности-eugene-schwartz--тип-хука)). Стадия осознанности
определяет класс хука: problem-aware аудитории нельзя показывать хук про продукт,
unaware — нельзя про решение.

### Шаг 2. Подбор триггеров
Из [Части II](#часть-ii-база-психологических-триггеров) выбери 5–7 триггеров, которые бьют
в найденные боли. Правило: минимум один триггер потерь (loss aversion), один социальный
(social proof / unity), один любопытства (information gap), один конкретики (anchoring / specificity).

### Шаг 3. Подбор паттернов
Из [Части III](#часть-iii-каталог-паттернов-хуков-20242026) выбери 6–8 паттернов под формат
(UGC / STATIC / ANIMATION / HUMAN). Проверь секцию анти-паттернов — не бери выгоревшие
механики как основу, только как сырьё для ремикса.

### Шаг 4. Генерация — минимум 10 хуков
Сгенерируй **не меньше 10** хуков (лучше 12–15, чтобы было из чего отсеять слабые).

Квоты разнообразия пачки:
- **Стадии осознанности**: покрой минимум 3 стадии по Шварцу (пост-Andromeda Meta сама
  матчит объявление с пользователем — разнообразие стадий в пуле вознаграждается).
  Для проблемного COM-сегмента ориентир: 1 unaware, 3–4 problem-aware,
  2–3 solution/mechanism, 2 product-aware/proof, 1 most-aware/offer.
  Все квоты — ориентир, не жёсткое правило: если персона явно сконцентрирована
  в одной стадии, скоси распределение к ней и напиши одно предложение почему
- **Семейства тактик**: и конкретно-промо (цифра, цена, оффер), и pattern-interrupt/
  когнитивные (confession, contrarian, warning) — победители Motion 2026 в обоих семействах
- **Классы** — не больше 3 хуков одного класса:

| Класс | Механизм |
|-------|----------|
| Pain / negativity | Негативное смещение, боль в формулировке клиента |
| Loss / упущенное | Loss aversion: что человек теряет каждый месяц бездействия |
| Curiosity gap | Открытая петля, недосказанность (Лёвенштейн, Zeigarnik) |
| Social proof / story | История «такого же как ты» с конкретным результатом |
| Identity / call-out | Обращение к идентичности без нарушения политики Meta (см. ниже) |
| Contrarian / pattern interrupt | Слом ожидания, «не делай X», анти-совет |
| Specificity / numbers | Конкретная цифра как якорь (€520 → €3200, 7 месяцев, 70%) |

Каждый хук — это ТРИ слоя, прописывай все:
1. **Verbal** — текст-оверлей на экране, ≤12 слов, языком клиента, без канцелярита
2. **Visual** — первый кадр (старт в середине действия, без fade-in; обязан работать без
   звука — 85% видео в FB смотрят в mute; движение/контраст/одна точка фокуса)
3. **Audio** — первая реплика (для видео): вариация verbal-слоя в разговорном регистре,
   не дубль; обязана работать и без картинки

Все три слоя выражают ОДИН концепт (правило конгруэнтности — рассинхрон даёт высокий
hook rate при провальном hold rate). Перед написанием сверься с бан-листом в
[Части III, §8](#8-бан-лист) («Представляем...», «Стоп, не листай», скриптованный позитив и т.д.).

### Шаг 5. Скоринг и ранжирование
Оцени каждый хук по 5 осям (1–5) и посчитай сумму:
- **Stop-power** — сила остановки скролла (неожиданность, движение, негатив, лицо)
- **Relevance** — точность попадания в боль/JTBD-силу персоны
- **Curiosity** — открыта ли петля: хочется ли узнать продолжение
- **Specificity** — есть ли конкретика (цифры, названия, детали), убивающая генерик
- **Believability** — не пахнет ли скамом/кликбейтом (перегретые обещания снижают
  и hook rate у холодной аудитории, и качество лида → CPQL)

Отсортируй по сумме. В финальный список — минимум 10, отсортированных от сильного к слабому.

### Шаг 6. Проверка на политику Meta
Meta запрещает хуки, утверждающие или подразумевающие персональные атрибуты зрителя.
Проверь каждый хук:
- ❌ «Ты сидишь без денег?» / «Твой минидзоб — тупик» (прямое утверждение о человеке)
- ✅ «Минидзоб — это ловушка. Вот почему» (утверждение о явлении)
- ✅ «Я 7 лет работала на складе...» (первое лицо, история)
- ❌ упоминание национальности/статуса зрителя («ты иммигрант из СНГ»)
- ✅ «для русскоязычных в Германии» (характеристика продукта, не зрителя)
Перепиши нарушающие формулировки через первое лицо, третье лицо или утверждение о явлении.

## Формат выдачи

ВСЕГДА используй эту структуру:

```markdown
# Хуки: {Персона} ({flow}, стадия осознанности: {stage})

## Разбор персоны
- Топ-боли: ...
- JTBD-силы: Push / Pull / Anxiety / Habit
- Контраст А→Б: ...

## Хуки (ранжированы по прогнозу hook rate)

### 1. {Короткое название} — {score}/25
- **Verbal**: «...»
- **Visual**: первый кадр — ...
- **Audio**: ...
- **Паттерн**: {название из Части III}
- **Триггер**: {принцип + автор, напр. loss aversion (Канеман)}
- **Бьёт в**: {конкретная боль/сила персоны}
- **Почему остановит скролл**: 1–2 предложения
- **Риск**: {выгорание / политика Meta / believability — если есть}

... (минимум 10)

## Рекомендации к тесту
- Какие 3–4 хука запускать первыми и почему
- Что тестировать парами (один концепт × разные хуки)
```

Если пользователь просит добавить хуки в библиотеку (/library, таблица `hooks`) — предложи
для каждого выбранного хука: `name`, `template` (обобщённый шаблон с плейсхолдерами),
`description`, `examples` (2–3 вариации), следующий свободный H-код.

## Принципы качества

- **Язык клиента, не маркетолога.** Бери формулировки из pains дословно: «деньги заканчиваются
  за неделю до зарплаты» сильнее, чем «финансовые трудности». Отполированная фраза = реклама,
  живая фраза = человек. Рекламу скроллят.
- **Одна мысль на хук.** Хук с двумя идеями — это ноль идей за 2 секунды.
- **Конкретика бьёт абстракцию.** «€3200 в месяц» > «хорошая зарплата». «7 месяцев» > «быстро».
- **Не закрывай петлю.** Хук, который сам ответил на свой вопрос, не покупает досмотр.
- **Негатив работает, но следи за качеством лида.** Чистый страх даёт дешёвый клик и дорогой
  CPQL. Балансируй: страх в хуке → надежда в первых секундах боди.
- **Не выдумывай цифры.** Используй только факты из персоны/брифа (€520, €3200, 7 месяцев,
  DEKRA, Bildungsgutschein). Если фактов нет — ставь плейсхолдер {X} и пометь, что нужна фактура.
  Арифметика из фактов персоны (например, 2800 − 520 = 2280) допустима, но помечай такие
  цифры «сверить фактуру» — и то же для двусмысленных триггеров из брифа: выбери самое
  защищаемое прочтение и отметь, что нужен факт-чек.

# Часть I. JTBD → хуки: методология

Как из файла с персонами и JTBD получить сырьё для хуков.

## 1. Четыре силы прогресса (Bob Moesta / Clayton Christensen)

Каждая покупка — «переключение», решаемое перетягиванием каната:
**Push** (фрустрация текущим) + **Pull** (притяжение новой жизни) против
**Anxiety** (страх нового решения) + **Habit** (инерция привычного).

### Главное правило распределения сил по крео

| Сила | Куда идёт | Почему |
|------|-----------|--------|
| **Push** | ХУК | Главный источник хуков: об этом люди говорят сами, это узнаваемая сцена |
| **Pull** | ХУК | Образ «нового себя» после переключения, с датой и цифрой |
| **Anxiety** | БОДИ (сек. 5–30) | Хук с успокоением («это проще, чем кажется») отвечает на возражение, которое ещё не прозвучало — проваливается |
| **Habit** | БОДИ | Инерцию ломают доказательствами, не первой секундой |

**Исключение — anxiety-inversion hook**: для «застрявшего» сегмента (знает о решении,
но не конвертится) работает прямое называние страха: «Боишься, что не потянешь учёбу
на немецком? Именно этот страх...». Использовать точечно, не как основу пачки.

### Шаблоны
- **Push-хук**: `[конкретная сцена провала старого способа] + [эмоциональная цена]`
- **Pull-хук**: `[конкретное после-состояние с временной меткой]` — «Через 7 месяцев ты можешь...»

## 2. Struggling moments — снимаемые сцены

Лучшие push-хуки гиперконкретны и сенсорны: не «устала от работы», а
«25-го числа открываешь банковское приложение и считаешь, что осталось».

**Процедура**: для каждой персоны возьми 3–5 болей из pains → перепиши каждую как
СНИМАЕМУЮ СЦЕНУ (кто, где, что делает, что чувствует). Эта сцена — одновременно
verbal-хук и бриф первого кадра (visual-хук).

## 3. Job story → 3 хука механически

Формат Intercom: `Когда [ситуация], я хочу [мотивация], чтобы [результат]`.
Каждая job story раскладывается на 3 слота хуков:

1. **Situation hook** — веди с «Когда»: «Когда тебе 40 и ты снова "на старте" в чужой стране...»
2. **Motivation hook** — веди с желания, оформленного как запретное/легализованное:
   «Хотеть нормальную профессию, а не "любую работу" — это нормально»
3. **Outcome hook** — веди с «чтобы», с конкретикой (цифра, дата, артефакт):
   «...чтобы на стене висел сертификат DEKRA, а в договоре стояло €3200»

Это основной генеративный ход скилла: одна job story = минимум 3 хука.

## 4. Майнинг языка клиента (Joanna Wiebe / Copyhackers)

Не пиши копирайт — укради его у клиента. Канонический кейс Copyhackers: заголовок,
взятый дословно из отзыва на Amazon («If you think you need rehab, you do»), дал
**+400% кликов** против «профессионального» заголовка. Механизм: точная формулировка
клиента вызывает самоузнавание, недоступное языку маркетолога.

**Процесс**:
1. Источники: поля pains/triggers персон (уже дословные), отзывы на конкурирующие курсы,
   группы «работа в Германии», треды про Jobcenter, комментарии под контентом о смене профессии
2. Тегируй фразы: боль / желаемый результат / возражение / триггерное событие /
   идентичность («я из тех, кто...») / жалоба на прошлое решение
3. Ранжируй по частоте × эмоциональному заряду (мат, капс, превосходные степени = высокий заряд)
4. **Правило дословности**: первая строка хука содержит минимум одну фразу клиента
   без правок или близкий парафраз с сохранением ритма и регистра
5. **Тест каждого хука**: «Мог бы клиент сказать это слово в слово?» Если нет — переписать
6. Фразы сравнения («пробовал X, но...») — готовые pattern-interrupt хуки против
   альтернатив: «просто найди любую работу», минидзоб-беговая дорожка, бесплатные
   бесполезные курсы от Jobcenter

## 5. Стадии осознанности (Eugene Schwartz) → тип хука

70–80% перфоманса Meta — креатив (AppsFlyer), и он начинается с попадания
сообщения в стадию осознанности:

| Стадия | Тип хука | Шаблон |
|--------|----------|--------|
| **Unaware** | Pattern interrupt, история, identity call-out — НИКОГДА продукт | «Никто не говорит об этом, но...» |
| **Problem-aware** | Call-out боли, чек-лист симптомов, цена бездействия | «Отправила 50 Bewerbungen и тишина? Смотри» |
| **Solution-aware** | Сравнение категорий, уникальный механизм, «почему X не работает» | «Почему "сначала выучи немецкий" — самый МЕДЛЕННЫЙ путь к карьере в Германии» |
| **Product-aware** | Доказательства: до/после, тестимониал, артефакт | «Из уборщицы в Buchhalterin за 7 месяцев — вот её Gehaltsabrechnung» |
| **Most-aware** | Оффер, дедлайн, убийца возражения | «Jobcenter платит 100%. Набор закрывается в пятницу» |

### Sophistication (вторая ось Шварца) → эскалация клейма
Рынок онлайн-образования для русскоязычных в DACH ≈ стадия 3–4 → вести с
**уникального механизма**, а не с обещания: «на русском + DEKRA + Bildungsgutschein» —
это механизм-клеймы. На стадии 5 (выжженный рынок) работают только identity-хуки —
зритель входит в рекламу через идентичность, не через желание.

### Правило эпохи Andromeda (2025–2026)
Не выбирай одну стадию на кампанию. Пачка из 10 хуков должна покрывать ≥3 стадии.
Meta сама сматчит объявление с пользователем — разнообразие стадий внутри пула
вознаграждается алгоритмом.

## 6. Таксономия хуков: когда какой класс выигрывает

- **Pain-хуки** — лучшие для problem-aware холодного трафика; реактивируют срочность
  у тех, кто нормализовал свою боль. Риск: слишком общая боль → сочувствующие клики без квала.
- **Desire/outcome-хуки** — выигрывают на рынках с усталостью от рекламы: боль-каллаут
  «пахнет рекламой», результат «пахнет свидетельством». Требуют пруфа сразу после.
- **Curiosity-хуки** — лучшие скролл-стопперы (максимальный hook rate), но худшие
  квалификаторы: без квалифицирующей второй строки надувают CPL мусорными лидами.
- **Identity-хуки** — после урезания таргетинга Meta креатив = таргетинг: каллаут
  идентичности делает отбор аудитории, который больше не делает ad set.
  Стабильно сильны для иммигрантских/комьюнити вертикалей.
- **Proof/social-хуки** — для product-aware и покупок с высоким порогом доверия
  (образование — именно такая).
- **Fear/loss-хуки** — мощные, но выгорают быстрее всех и трутся о политику Meta.

**Эмпирический паттерн**: curiosity/question/surprise выигрывают по hook rate;
problem-solution/proof/story выигрывают по конверсии. Судить пачку по CPL/CPQL,
не только по hook rate.

## 7. Тестирование хуков (2024–2026)

- **Hook-first testing**: боди константа, варьируются только первые 3 секунды.
  Hook swap — самая дешёвая единица итерации: пересобери боди виннеров с новыми хуками
  раньше, чем делать новые концепты.
- **3–5 вариантов на концепт**, каждый — ПРИНЦИПИАЛЬНО разный класс хука (не микро-твики).
  8 похожих хуков = фидбек по одному направлению, не по восьми (аукцион дедуплицирует).
- **Чтение метрик**: hook rate по ~2000+ показов на вариант; лиды — при спенде 2–3× target CPL.
- **Лестница диагностики**:
  - высокий hook + низкий hold = bait-and-switch (хук врёт про боди)
  - низкий hook + хороший CPL = квалифицирующий хук — НЕ «чинить», оставить
- **Структура**: 10–20 разнообразных вариантов в один ASC/broad пул.
- **Библиотека**: 20–30 проверенных шаблонов; сплит ~70/30 проверенное/эксперимент.

## 8. Специфика вертикали: образование / смена карьеры

Высокий порог доверия (месяцы жизни + деньги/бюрократия). Что работает:

- **Проверяемые результаты и прозрачность зарплат** бьют вдохновение: конкретные
  цифры, именованные артефакты (DEKRA-Zertifikat, Arbeitsvertrag, Gehaltsabrechnung),
  «покажи квитанцию».
- **Risk-reversal как механизм-хук**: «государство платит 100% (Bildungsgutschein)» —
  одновременно механизм, убийца тревоги и most-aware оффер. Сильнейший одиночный энгл для GOV.
- **Проверенный набор энглов для career-switch аудитории**:
  1. Потолок дохода — «работаешь на двух работах, а на счету ноль»
  2. Тупик/выгорание тела — физическая работа изнашивает, лестницы нет
  3. Возврат статуса — «дома ты был специалистом, здесь — "помощник"»
  4. Безопасность семьи — стабильный офис глазами детей/партнёра
  5. Бюрократия наизнанку — «система, которая тебя мучает (Jobcenter, Ämter), может оплатить твою карьеру»
  6. Рефрейм языкового барьера — «обучение на русском» снимает главное habit-оправдание
  7. Рефрейм возраста — «45 — не поздно», разрешение на идентичность
  8. Peer proof — тестимониал того же происхождения/возраста: «Ирина, 42, из Алматы...»
- Гибкость (онлайн, свой график, совмещение) — материал БОДИ (убийца тревоги), не хука.

# Часть II. База психологических триггеров

Каждый триггер: механизм → правило трансформации в хук → примеры под вертикаль
(курс «Бухгалтер в Германии», русскоязычные иммигранты, COM/GOV).

## Канеман

### System 1 Capture
- **Механизм**: решение «смотреть/скроллить» принимается досознательно за <1 сек. System 2 никогда не увидит хук, который отбросила System 1.
- **Правило**: в хуке обязан быть примитив System 1 — лицо, движение, цифра, угроза, вопрос к «ты», слом паттерна. Никогда не открывать абстракцией («качественное образование») — только конкретный образ или фраза, которую поймёт семилетка.
- **Примеры**: «Стоп. Ты сколько сейчас получаешь?»

### Loss Aversion (теория перспектив)
- **Механизм**: потери весят ~2–2.5× больше эквивалентных выгод.
- **Правило**: переформулируй выгоду оффера как ТЕКУЩУЮ потерю, которую зритель уже несёт. Формула: «Каждый [период] без X ты теряешь [конкретная вещь]». Лучше всего на стадии problem-aware.
- **Примеры**: «Ты теряешь 20 000€ в год, работая не по специальности» · «Твой диплом теряет ценность каждый год, пока ты его не конвертируешь»

### Anchoring
- **Механизм**: первая увиденная цифра становится точкой отсчёта для всех последующих суждений.
- **Правило**: открывай большой цифрой (зарплата, цена бездействия, цена конкурента) ДО своей цифры. Якорь должен прийти первым.
- **Примеры**: «Бухгалтер в Германии получает 3800€ в месяц. А ты?» · «Umschulung в частной школе стоит 15 000€. Jobcenter платит за тебя всё»

### Availability Heuristic
- **Механизм**: лёгкость вспоминания примера = воспринимаемая вероятность. Один яркий случай бьёт статистику.
- **Правило**: результат должен быть мгновенно представим — один названный человек, одна сцена, один скриншот расчётного листа. Не «многие выпускники нашли работу», а один Zahlschein.
- **Примеры**: «Вот расчётный лист Оксаны из Дортмунда — 3200€ брутто, первый год после курса»

### Framing Effects
- **Механизм**: логически одинаковые утверждения дают разные решения в зависимости от рамки.
- **Правило-множитель**: один факт → 4 рамки → 4 отдельных крео: gain / loss / social («такие как ты уже...») / temporal («через 7 месяцев...»).
- **Примеры**: Gain: «Через 7 месяцев — сертификат DEKRA». Loss: «Ещё 7 месяцев на складе — или 7 месяцев до профессии. Время пройдёт одинаково»

### Cognitive Ease / Processing Fluency
- **Механизм**: лёгкое в обработке ощущается более правдивым и знакомым.
- **Правило**: хук ≤12 слов, частотная лексика, ритм, контрастный читаемый текст. Для иммигрантов родной язык в чужой ленте — сам по себе скачок беглости и слом паттерна.
- **Примеры**: русский текст в немецкой ленте — уже хук. «Работа. Зарплата. Уважение. По-русски объясним, как»

### WYSIATI (What You See Is All There Is)
- **Механизм**: System 1 строит связную историю только из предъявленного, не спрашивая, чего не хватает.
- **Правило**: полностью контролируй рамку — предъяви 2–3 факта, делающих вывод неизбежным, опусти остальное. Хук, который спорит, — проигрывает.
- **Примеры**: «В Германии не хватает 90 000 бухгалтеров. Ты говоришь по-русски и умеешь считать. Всё»

### Base Rate Neglect
- **Механизм**: яркая индивидуальная история перекрывает статистику.
- **Правило**: не веди с агрегированной статистики рынка — веди с одной истории, на которую зритель наложит себя. Обратный ход: шокирующий base rate работает как якорь, когда он ПРО НИХ.
- **Примеры**: «87% приехавших с высшим образованием работают не по специальности. История Лены — о том, как выйти из этих 87%»

### Peak-End Rule
- **Механизм**: опыт запоминается по пику и концовке, не по среднему.
- **Правило**: для хуков — «открывай кульминацией»: самый эмоциональный кадр в секунду 0–1. Покажи результат сначала, объясняй потом.
- **Примеры**: видео открывается моментом получения сертификата DEKRA / первого немецкого расчётного листа, потом: «А начиналось всё с уборки отелей»

## Ариели

### Relativity & Decoys
- **Механизм**: абсолютную ценность оценить нельзя — сравниваем с соседними опциями. Непривлекательная «приманка» делает целевой вариант очевидным.
- **Правило**: встрой сравнение В ХУК: твой оффер против заведомо непривлекательной альтернативы (остаться как есть, дорогая школа только на немецком, годы Ausbildung).
- **Примеры**: «Ausbildung — 3 года на немецком. Наш курс — 7 месяцев на русском. Сертификат — DEKRA» · «Учить немецкий до C1 — 2 года. Стать бухгалтером — 7 месяцев»

### FREE! / Zero-Price Effect
- **Механизм**: ноль — не низкая цена, а эмоциональная категория, полностью убирающая воспринимаемый риск.
- **Правило**: если что-то в воронке реально бесплатно — это слова 1–3 хука. Для GOV это вся стратегия: государство платит = БЕСПЛАТНО для зрителя.
- **Примеры (GOV)**: «БЕСПЛАТНО. Государство Германии оплатит тебе новую профессию. Полностью» · «Jobcenter заплатит 100% за твоё обучение. Ты не знал?»

### Endowment / Ownership Effect
- **Механизм**: переоцениваем то, чем (даже виртуально) владеем; воображаемое владение включает loss aversion при отказе.
- **Правило**: посели зрителя в результат с первой секунды — второе лицо, настоящее время: «твой стол, твой договор, твой Gehalt». Сначала виртуальное владение, потом оффер.
- **Примеры**: «Представь: понедельник, 9:00, твой офис, твой кофе, твои 3500€» · «Твоё имя. Твой Arbeitsvertrag. Unbefristet»

### Expectation Effects
- **Механизм**: ожидания физически меняют восприятие; лейбл задаёт оценку до доказательств.
- **Правило**: высокостатусный лейбл (DEKRA, «немецкий стандарт») — ДО любых деталей продукта. Лейбл — якорь качества хука.
- **Примеры**: «Сертификат DEKRA. Тот самый, который немецкие работодатели узнают с первой строчки резюме»

### Pain of Paying
- **Механизм**: платёж активирует зоны боли; заметность платежа снижает конверсию даже при той же цене.
- **Правило (критично для COM!)**: никогда не веди с цены; если цена нужна — разложи в привычный тривиальный эквивалент или подай как перекладывание, не трату.
- **Примеры (COM)**: «Курс окупается первой зарплатой. Одной» · «Меньше, чем ты тратишь на кофе навынос за год. Только это — профессия навсегда»

### Identifiable Victim/Hero Effect
- **Механизм**: один названный человек даёт кратно больше эмоции, чем статистика.
- **Правило**: хук = один человек, одно имя, одна конкретная деталь. Хребет каждого UGC-формата. Отличие от availability: здесь человек И ЕСТЬ сообщение.
- **Примеры**: «Меня зовут Ирина. Год назад я мыла подъезды в Кёльне. Сейчас я закрываю месяц в немецкой фирме»

### Hot-State / Arousal Decisions
- **Механизм**: решения в возбуждённом состоянии радикально отличаются от холодных; возбуждение сужает фокус.
- **Правило**: хук СОЗДАЁТ горячее состояние (возмущение, зависть, надежду) до любого рационального контента. Эмоция в 0–2 сек, логика с 5-й. Гнев на несправедливость — самое дешёвое возбуждение для иммигрантского сегмента.
- **Примеры**: «Тебе с двумя высшими говорят "нужен C1", а бухгалтеру хватает B1. Тебе просто не сказали»

## Чалдини

### Social Proof
- **Механизм**: в неопределённости копируем ПОХОЖИХ на нас.
- **Правило**: похожесть бьёт объём. «347 русскоязычных в Германии» > «10 000 студентов». Называй совпадающий атрибут (язык, город, прошлая работа).
- **Примеры**: «Уже 300+ русскоязычных прошли этот путь. Вот их города: Берлин, Ганновер, Лейпциг...» · «Почему все девочки в моём Jobcenter записались на этот курс?»

### Authority
- **Механизм**: символы легитимной экспертизы включают доверие и отключают проверку.
- **Правило**: один узнаваемый символ авторитета в первом кадре: логотип DEKRA, «по стандарту IHK». Для GOV авторитет — само государство («одобрено для Bildungsgutschein»).
- **Примеры**: «Единственный курс бухгалтерии на русском с сертификатом DEKRA»

### Scarcity
- **Механизм**: угроза потери доступности = loss aversion применительно к офферу; ограничение подразумевает ценность.
- **Правило**: дефицит должен быть ПРАВДОПОДОБНЫМ и конкретным (размер потока, окно набора, бюджетные циклы Bildungsgutschein) — фейковые таймеры сжигают доверие в тесном комьюнити. Дефицит ВОЗМОЖНОСТИ (окно на рынке труда) безопаснее дефицита продукта.
- **Примеры**: «Набор потока закрывается 1-го — группа 25 человек, по-другому не учат» · «Дефицит бухгалтеров в Германии не будет вечным. Первые успеют»

### Reciprocity
- **Механизм**: получивший первым чувствует долг ответить (вниманием, контактом).
- **Правило**: хук ДАЁТ ценность сразу — факт, чек-лист, мини-урок — до любой просьбы.
- **Примеры**: «Сохрани: 5 фраз для собеседования в немецкой бухгалтерии» · «Держи список: что Jobcenter оплачивает в 2026 — многие не знают про пункт 3»

### Commitment & Consistency
- **Механизм**: маленькие «да» создают давление действовать последовательно.
- **Правило**: открой вопросом, на который можно ответить только «да» — микро-да коммитит. Или воззови к ПРОШЛОМУ обязательству.
- **Примеры**: «Ты переехала в Германию ради лучшей жизни, так? Тогда почему до сих пор на минидзобе?»

### Liking
- **Механизм**: похожесть, знакомость, комплименты — покупаем у таких же, как мы.
- **Правило**: говорящая голова = сама персона: тот же акцент, та же история переезда, та же кухня в кадре. Первая строка устанавливает похожесть, не оффер.
- **Примеры**: «Я тоже думала, что в 40 лет с русским дипломом в Германии ничего не светит...»

### Unity (общая идентичность)
- **Механизм**: сильнее liking — «свой»; общая этничность/опыт делает влияние почти автоматическим.
- **Правило**: обратись к ин-группе по имени в словах 1–2. Рамка «наши в Германии». Сильнейший одиночный триггер-таргетер для этой вертикали.
- **Примеры**: «Наши девочки в Германии, это для вас» · «Если ты приехала по §24 — ты поймёшь, о чём я»

### Pre-suasion: привилегированные моменты
- **Механизм**: то, что держит внимание В МОМЕНТ решения, оценивается как важное и причинное; опенер задаёт рамку оценки оффера.
- **Правило**: ТЕМА хука (не только содержание) задаёт рамку. Открыл «несправедливой зарплатой» → оффер оценивается как восстановление справедливости. Открыл «будущим ребёнка» → как родительский долг. Выбери pre-suasive рамку под персону, потом пиши хук внутри неё. Вопросы — машины привилегированных моментов.
- **Примеры**: «Что ты ответишь ребёнку на вопрос "мама, кем ты работаешь?"» · «Ты из тех, кто доводит начатое до конца?»

## Другие

### Лёвенштейн — Information Gap Theory (КРИТИЧНО для хуков)
- **Механизм**: любопытство = зудящий разрыв между известным и желаемым узнать. Разрыв должен быть конкретным, заметным и КАЖУЩИМСЯ закрываемым — полная загадка не зудит.
- **Правило**: формула = [конкретный известный контекст] + [один удержанный элемент] + [обещание закрытия]. Усилители: «почему», «одна вещь/ошибка», цифры («3 из 5»), отрицание ожидания («это не то, что ты думаешь»). Разрыв должен быть ЧЕСТНЫМ — видео обязано его закрыть, иначе умирает retention.
- **Примеры**: «Есть профессия в Германии, куда берут с русским дипломом и B1. И это не программист» · «Почему Jobcenter сам предлагает этот курс — но только тем, кто спросит?» · «Сумму моей первой немецкой зарплаты назову в конце. Сначала — как я к ней пришла»

### Талер — Mental Accounting & Nudge
- **Механизм**: деньги лежат на невзаимозаменяемых ментальных счетах; рамка счёта меняет готовность тратить.
- **Правило**: перенеси цену курса со счёта «расход» на счёт «инвестиция/доход», или (GOV) на «счёт государства, не мой». Nudge: подача записи как дефолтного следующего шага, не опции.
- **Примеры**: «Это не трата. Это перекладывание денег из 2026 в зарплату 2027» · «Твой Bildungsgutschein уже лежит в Jobcenter. Его просто нужно забрать»

### Кольер — войди в разговор, который уже идёт в голове
- **Механизм**: разум впускает сообщения, продолжающие его текущий внутренний монолог; остальное — шум.
- **Правило**: хук = дословная транскрипция внутренней фразы персоны в 23:00 за скроллом. Мастер-тест для каждого хука: «Сказала бы P2 эту фразу самой себе?»
- **Примеры**: «"Мне уже 42, поздно что-то менять" — ты это себе говоришь примерно раз в неделю, да?» · «"Вот выучу немецкий до C1, тогда..." — сколько лет ты уже это говоришь?»

### Халберт — Starving Crowd
- **Механизм**: голод рынка бьёт качество копирайта; лучший хук называет голод напрямую самому голодному сегменту.
- **Правило**: целься в момент ОСТРОЙ боли (письмо с отказом, унизительная смена, термин в Jobcenter), не в хроническое состояние. Ситуативный таргетинг внутри хука.
- **Примеры**: «Опять Absage? Прочитай это до следующей отправки резюме» · «Завтра термин в Jobcenter? Скажи там одну фразу — и они оплатят тебе профессию»

### Шугерман — Slippery Slide & Seeds of Curiosity
- **Механизм**: единственная задача предложения 1 — заставить прочитать предложение 2; микро-клиффхэнгеры держат скольжение.
- **Правило**: хук должен быть НЕЗАВЕРШЁННЫМ — грамматически или информационно. Короткое первое предложение (1–4 слова) даёт максимальный вход. Посади форвард-тизер в первые 3 сек.
- **Примеры**: «Я ошибалась.» · «330 000 вакансий. Одна проблема.» · «Сейчас будет неприятная правда про ваш диплом»

### Уоррен — One-Sentence Persuasion (5 слотов)
- **Механизм**: «Люди сделают что угодно для тех, кто поощряет их мечты, оправдывает их неудачи, успокаивает их страхи, подтверждает их подозрения и помогает кидать камни в их врагов». Пять обходов сопротивления — ни один не спорит.
- **Правило**: это генератор 5 типов хуков. «Оправдай неудачи» — уникально силён для смены карьеры: сначала сними самообвинение, потом продавай. «Подтверди подозрения» + «камни во врагов» = system-blame хуки (враг: бюрократия, непризнание дипломов, работодатели с требованием C1).
- **Примеры**: Justify: «Ты не нашла работу по специальности не потому, что плохо старалась. Система признания дипломов реально сломана» · Rocks: «Работодатели требуют C1 там, где хватает B1. Их право. А это — твой обходной путь» · Dreams: «Офис, белая зарплата, отпуск 30 дней — это не "может быть", это план на 7 месяцев»

### Эффект Зейгарник
- **Механизм**: открытые петли держатся в памяти и создают напряжение до закрытия (~2× лучше запоминание).
- **Правило**: открой петлю в секунду 1, закрой только на CTA. Отличие от curiosity gap: Зейгарник — про удержание ЧЕРЕЗ ВСЁ видео (структура, не только опенер).
- **Примеры**: «Три документа отделяют тебя от профессии в Германии. Третий — самый неожиданный»

### Negativity Bias
- **Механизм**: негативные стимулы захватывают внимание быстрее и держат дольше (эволюционный приоритет угроз).
- **Правило**: негативный опенер → позитивное разрешение. Слова: ошибка, никогда, хватит, обман, поздно, теряешь. Осторожно с Meta: негатив направляй на себя или систему, не на зрителя (политика + бэклэш).
- **Примеры**: «Хватит.» · «Самая дорогая ошибка иммигранта — ждать идеального немецкого» · «Никогда не соглашайся на минидзоб "временно". Вот почему»

### Von Restorff Effect (изоляция/отличимость)
- **Механизм**: замечается и запоминается то, что отличается от контекста. Контекст = ЛЕНТА, она и есть настоящий конкурент.
- **Правило**: проектируй хуки против ленты, не против конкурентов: неожиданный визуал (расчётный лист крупно, рукописная записка, письмо из Jobcenter), русский текст в немецкой ленте, тишина там, где лента шумит, «некрасивый» нативный UGC там, где лента полирована. Ротируй отличимость — она выгорает.
- **Примеры (visual-first)**: кадр 1 = бумага Bildungsgutschein на весь экран; кадр 1 = калькулятор с «3 517,00 €»

### Mere Exposure (слой ретаргетинга)
- **Механизм**: повторная экспозиция рождает симпатию через беглость (если старт не негативный).
- **Правило**: держи один константный узнаваемый элемент во всех крео пачки (тот же ведущий, тот же цветовой чип, тот же опенинг-бит), чтобы показы 2–5 накапливались, а не стартовали заново. Хук для ретаргетинга может ссылаться на знакомость: «Ты уже видела меня в ленте...»

### Огилви
- **Правило**: заголовок — 80% денег объявления; конкретика бьёт остроумие; флагируй аудиторию в заголовке; образование — обдуманная покупка, поэтому хук цепляет, а лендинг/копия несёт факты.
- **Примеры**: «Бухгалтер в Германии: инструкция для тех, кто приехал после 2022»

## Рабочие стеки триггеров

Триггеры редко работают поодиночке; лучшие формулы — стеки из 2–3:

1. **Loss aversion + Social proof** (= FOMO): «Пока ты думаешь, 300 русскоязычных уже получают немецкую зарплату бухгалтера»
2. **Curiosity gap + Authority**: «Jobcenter не обязан рассказывать тебе про эту программу. Но обязан оплатить, если попросишь»
3. **Unity + Justify failures (Уоррен)** — сильнейший холодный UGC-опенер для иммигрантских вертикалей: «Наши в Германии не сидят на Bürgergeld потому что ленивые. Им просто никто не объяснил систему»
4. **Anchoring + Zero-price (GOV)**: «Обучение стоит 9 000€. Ты заплатишь 0€. Разницу платит государство»
5. **Negativity + Curiosity + Zeigarnik**: «Я потеряла 2 года в Германии из-за одного мифа. Досмотри — назову его в конце»
6. **Endowment + Anchoring (COM)**: «Твои будущие 3500€/мес. Курс — половина одной такой зарплаты»
7. **Confirm suspicions + Throw rocks + Reciprocity** — семейство «system-hack» хуков, топ для скептичной (изощрённой) аудитории: подтверди обиду, назови врага, подари обход
8. **Анти-стеки**: Scarcity + FREE для GOV читается как скам («бесплатно и срочно»); Authority + тяжёлый негатив размывают друг друга

## Карта триггер × стадия осознанности

| Стадия | Лучшие триггеры | Режим хука |
|--------|-----------------|------------|
| **Unaware** | Von Restorff, negativity bias, identifiable hero, внутренний монолог (Кольер), Unity | История/слом паттерна. Продукт НЕ упоминать. «Меня зовут Ирина, я мыла подъезды...» |
| **Problem-aware** | Loss aversion, justify failures, confirm suspicions, availability (яркий случай), hot state | Назови боль их словами, приоткрой дверь: «Ты не виновата. Но выход есть» |
| **Solution-aware** | Curiosity gap, anchoring (сравнения), relativity/decoy | Дифференцируй механизм: «Все учат немецкий. Умные учат профессию, где хватает B1» |
| **Product-aware** | Social proof, authority (DEKRA), endowment, expectation effects, mere exposure | Пруф + владение: «Вот дипломы наших выпускников этого месяца» |
| **Most-aware** | Scarcity, zero-price / снятие pain of paying, commitment, nudge-default | Сделка + дедлайн: «Поток закрывается 1-го. Bildungsgutschein покрывает 100%» |

**COM vs GOV**: COM (платят сами) — более изощрённая и ценово-защищённая аудитория → нужны снятие pain of paying, mental accounting, endowment, justify-failures. GOV конвертится на zero-price + authority + nudge-default.

# Часть III. Каталог паттернов хуков 2024–2026

Источники: Motion Creative Benchmarks 2026 (датасет $1.29B / 578 750 крео), открытый репо
motion-team/creative-strategy-skills, Dara Denney, Barry Hott, Savannah Sanchez,
Sarah Levinger, Mirella Crespi, Curtis Howland и практика перфоманс-команд.

## 1. Бенчмарки hook rate

Hook rate = 3-second plays ÷ impressions.

| Значение | Вердикт |
|----------|---------|
| < 20% | Хук пересобирать, не твикать |
| 20–25% | Базовый уровень («table stakes») |
| 25–30% | Крепко для большинства аккаунтов |
| 30–40% | Хорошо; цель 2026 (Motion, Taylor Sicard: планка 30%+) |
| 40%+ | Элита; алгоритм награждает низким CPM и охватом |

- **Hold rate** (15s/3s): цель ~40–50%
- **Поправка на плейсмент**: Reels идёт на 5–10 п.п. НИЖЕ ленты — судить по отдельной шкале
- Хит-рейт креативов в целом: 5–15%; ориентир производства ~1 новое объявление на $3K месячного спенда
- Пост-Andromeda: креатив выполняет работу таргетинга → хук = де-факто селектор аудитории
- Статика: hook rate нет; эквивалентный рычаг — первая строка primary text
  (~125 символов до «Ещё», ядро в первых ~35) и заголовок. Порядок сканирования:
  визуал → заголовок → CTA → текст
- Сильный хук в первые 3 сек → до +89% к completion rate (отчёт Meta 2025)

## 2. Слоёная модель хука

Хук — не одна строка, а стек (Motion):

```
Messaging angle (истина о клиенте) → Creative mechanic (когнитивный ход)
→ Hook (тактика × психологический триггер) → Visual format (сосуд)
```

Каждый видео-хук пишется в ТРИ слоя одновременно и раздельно:
- **SPOKEN** — первые слова (обязаны работать без видео)
- **VISUAL** — первый кадр/действие
- **TEXT OVERLAY** — текст на экране

Статика: первая строка primary text + заголовок-оверлей + первая строка кэпшена.

8 психологических триггеров внутри любой тактики: Pattern Interrupt, Identity Call-Out,
Pain Agitation, Curiosity Gap, Social Proof, Contrarian/Myth-Busting, Aspiration, Urgency.
**Лучшие хуки комбинируют два.** Выбор тактики диктуется стадией осознанности Шварца
(см. Часть I, §5).

Метод Dara Denney: «вставь curiosity gap или конфликтное утверждение, создающее
когнитивный диссонанс — мозг останется, чтобы его разрешить». Майнить референсы —
из превью YouTube (opt-in площадка, хуки жёстче), не из библиотек рекламы конкурентов.

## 3. Вербальные тактики

Топ-5 тактик Motion 2026 для брендов $1M+/мес: **Confession, Bold Claim, Relatability,
Contrast, Curiosity**. Победители кластеризуются в два семейства:
- **Конкретно-промо**: Newness, Sale, Price Anchor, Urgency — снижают когнитивное усилие
- **Pattern-interrupt/когнитивные**: Confession, Contrarian, Shocking Statement, Warning

В пачке хуков должны быть ОБА семейства.

| Тактика | Механизм | Шаблон / пример | Когда |
|---------|----------|-----------------|-------|
| **Confession** | Доверие через уязвимость | «Я ошибалась насчёт X» | Скептики, полированные категории |
| **Shocking Statement** | Мгновенный вызов допущениям | «Ты всю жизнь делаешь X неправильно» | Перенасыщенные ленты |
| **Contrarian** | Слом общепринятого | «Я работаю в Германии и НЕ учила немецкий до C1» | Образованные/скептичные |
| **Myth Busting** | «Тебе врали» | «"Сначала выучи язык" — миф, который стоит тебе лет» | Категории с дезинформацией |
| **Warning** | Останавливает дефолтное поведение | «Не соглашайся на минидзоб, пока не увидишь это» | Problem-aware перед неверным выбором |
| **Curiosity** | Открытая петля | «Есть профессия, куда берут с B1. Не программист» | TOF, низкая вовлечённость |
| **Identity Call-Out** | Самоотбор; сигнал алгоритму | «Для тех, кто приехал после 2022» | Ниши, точность > охват |
| **If-Then** | Условная самоквалификация | «Если работаешь на складе с дипломом — смотри» | Сегментированный DR |
| **Contrast** | Подсветка несоответствия | «2 дня работы здесь = €500. Там = €7» | Ценочувствительные |
| **Price Anchor** | Рефрейм цены через знакомое | «Меньше, чем кофе навынос за год» | Средний/высокий чек (COM) |
| **Question** | Зеркалит внутренний монолог | «Отправила 50 резюме и тишина?» | Problem-aware |
| **Explainer (Why)** | Образование через первопричину | «Почему твои Bewerbungen игнорируют» | Problem-aware |
| **How To** | Обещание инструкции | «Как получить профессию за 7 месяцев» | Активно ищущие |
| **Listicle** | Структурированная логика | «3 причины, почему Jobcenter одобряет этот курс» | Solution/product-aware |
| **Storytelling** | Вход в середину истории | «Три года назад я мыла офисы...» | Трансформации, эмоции |
| **Statistic** | Квантифицированный пруф | «87% работают не по специальности» | Аналитичные скептики |
| **Social Proof** | Консенсус | «300+ русскоязычных уже прошли» | Product-aware сомневающиеся |
| **Authority** | Регалии, не популярность | «Сертификат DEKRA» | Образование/финансы — скептики |
| **Reverse Psychology** | Реактанс | «Это не для тебя, если...» | Уставшие от рекламы |
| **Bold Claim** | Крупное обещание | «Ничего ближе к гарантии в Германии нет» | Выгоревшие категории |
| **Urgency / FOMO** | Давление времени / стадность | «Поток закрывается 1-го» | Most-aware, ретаргетинг |
| **Aspirational** | Желанная идентичность | «Кем ты представляешься на вопрос "кем работаешь?"» | TOF статус |
| **Direct Address** | Слом 4-й стены | «Эй, ты. Да, ты, листающая ленту» | Дёшево, но выгорает (см. §6) |

### Паттерны от практиков
- **Comment-Reply / Negativity hook** (Savannah Sanchez): реальный негативный коммент
  оверлеем → криэйтор отвечает на критику → переход в демо. Конфликт останавливает скролл.
  Боль обязана указывать на решение, иначе отваливаются.
- **Founder hook**: основатель объясняет, зачем построил, с гиперконкретными цифрами.
  Репорты: −25–35% CAC на ретаргетинге, видевшем founder-контент.
- **Us-vs-Them**: старый способ vs новый бок о бок; сильнее всего с явным визуальным контрастом.
- **POV hook**: «POV: ты приехала в Германию с дипломом, а работаешь на кассе» —
  identity call-out в нативной грамматике рилсов.

## 4. Нативные голосовые шаблоны

Свайп-файл структур из реального вирального контента (Motion hook-voice-patterns).
Использовать, когда триггер правильный, но хук «звучит сконструированно»:

- «**Я гейткипила** [нишевая вещь], но ладно...»
- «**А кто мне должен был сказать**, что [факт]? Никто. Узнала из тиктока.»
- «**То есть как это** [возможность существует]?!» (энергия открытия)
- «**Вот чего я не понимаю** — почему мы всё ещё [старое поведение], когда есть [лучше]?»
- «**[Индустрия] не хочет, чтобы ты знала это**, потому что тогда [последствие]»
- «**Если хочешь [X] — перестань [ожидаемое действие]**»
- «**В первый раз я сделала [ошибку]. Во второй — уже знала.**»
- «**Если бы у меня было 90 дней на [цель], вот что бы я сделала**» ← отличный фит для образования
- «**Этот вопрос для [гипер-конкретная аудитория] и только для них**»
- «**Небольшое предупреждение** — [warning]»
- «**Спасибо всем, кто говорил мне [X] — вы были правы**»

Стандарты письма (Motion): голос ЧИТАТЕЛЯ, не бренда; конкретные цифры и сроки;
вести с боли/желания, никогда с названия продукта; читать вслух — «звучит как реклама →
переписать»; варьировать триггер по пачке.

## 5. Визуальные механики

Правила первого кадра:
- Продукт или лицо в центральной трети; **старт в середине действия, никаких fade-in**
- Одна точка фокуса; читаемо на мобильном
- **Обязан работать без звука** (85% видео в FB смотрят в mute)
- Движение/контраст в кадре 1: быстрый зум, падение объекта, резкий кат, скриншот

Именованные визуальные приёмы (Savannah Sanchez и др.):
- **Post-it reveal** — вопрос на стикере поверх объекта, отклеивание = ответ
- **Blurred-focus** — текст наводится из размытия (принудительное внимание)
- **«Меня всё время спрашивают...»** — реплика + проп
- **Silent review / rapid-fire Q&A / cliffhanger-слайдшоу / «Не покупай это»**
- **Prop-out-of-context** — предмет в неожиданном месте: визуал ломает паттерн, обещание остаётся ясным
- **Говорить одно, показывать противоречащее** (контраст-как-визуал)

Форматы-сосуды для статики (несут хук сами по себе):
**Native Text Overlay** (бытовое фото + нативная подпись — убивает распознавание рекламы),
**скриншот Notes App**, **скриншот интерфейса ChatGPT**, **Post-It**, **письмо**
(конверт Jobcenter!), **мем-шаблон**, **One Shot** (один клип <10 сек + одно предложение —
неподвижность как pattern interrupt), **Before/After** (осторожно с политиками).

Наши козыри Von Restorff: бумага Bildungsgutschein крупно, расчётный лист с «3 517,00 €»,
письмо с Absage, календарь «7 месяцев», русский текст в немецкой ленте.

## 6. Анти-паттерны: что выгорело / что растёт

### Выгорело (2025–2026) — не брать как основу
- Высокоэнергетичный direct-to-camera «Я ДОЛЖНА рассказать вам об этом!!» —
  **усталость от формата**, не от криэйторов: та же структура + та же эмоциональная арка
  = мгновенно распознаётся как реклама
- «Стоп! Не листай!» — прямой приказ выгорел
- Generic «TikTok made me buy it», переполированный UGC — «UGC, который выглядит как
  реклама, работает как реклама»
- **Generic AI slop**: тысячи брендов льют одинаковые AI-визуалы/роботические скрипты —
  одинаковость = драйвер усталости №1 в 2026
- Скриптованный позитив: чем энергичнее позитив в опенере, тем более скриптовым он читается.
  Выигрывающая энергия UGC — «не верю, что говорю это вслух», а не «этот продукт изменил мою жизнь»

### Растёт
- **Ugly ads / lo-fi** (Barry Hott): «выглядит как реклама → маркетинг-слепые скипают».
  Аудит «Секунды 0»; язык клиента, не бренд-бука
- **Конкретно-промо хуки** (цена, новизна) обгоняют «остроумные» на масштабе —
  снижают когнитивное усилие
- **Confession/Contrarian** когнитивное семейство
- **Медленный экспертный контент**: подкаст-стиль, VSL, «голос прожитого опыта» —
  нативен и обезоруживает (Mirella Crespi)
- **Скорость хуков через AI** — но победители используют AI для объёма РАЗНЫХ идей, не клонов
- **Реальная человеческая фактура** как контр-тренд AI: «чем больше AI-контента, тем сильнее
  жажда настоящего»

## 7. Специфика лидгена / образования

- Главное правило: креатив обязан ответить «**как будет выглядеть моя жизнь после курса**»
  в первые 3 секунды — иначе бюджет горит
- Лучшие тактики для career-change образования: Identity Call-Out, If-Then,
  Contrarian/Myth-busting о категории («не нужен идеальный немецкий»), Authority (DEKRA),
  Statistic, Storytelling из середины арки («Три года назад я мыла офисы...»),
  «Если бы у меня было 90 дней...», **Reframe** («тебе говорили, что проблема в X;
  на самом деле — в Y») для тех, кто уже пробовал и обжёгся
- Воронка: холодный трафик = видео с жёстким 3-сек хуком; тёплый/ретаргетинг конвертится
  на статике с крупным визуалом и короткой копией
- Хуки зеркалят внутренний монолог персоны ЕЁ словами — майнить отзывы/комменты
  (Sarah Levinger: «95% решений подсознательны», собирать эмоциональные данные)

## 8. Бан-лист

Никогда не открывать хук с:
- «Представляем...» / «Знакомьтесь...» / «Вы ищете...?»
- Названия продукта/бренда первым словом
- «Стоп! Не листай!»
- Высокоэнергетичного скриптованного позитива
- Fade-in, логотипа, титульной заставки

## 9. Методология тестирования (сжатая)

1. Заморозь всё, кроме секунд 0–3: то же боди, CTA, музыка, криэйтор; меняется только хук
2. 3–5 вариантов на тест, КАТЕГОРИАЛЬНО разных (разные семейства тактик, не 5 фразировок
   одной идеи). Сначала найди выигрывающую категорию, потом оптимизируй внутри неё
3. Суди сначала по hook rate, потом по CPA — хук даёт разброс 40–60% на одинаковом боди
4. Виннер → следующая волна итераций внутри выигравшей категории до того, как виннер выгорит
5. Архивируй как тегированную библиотеку (тактика, триггер, персона, стадия) — ищи
   недопредставленные тактики перед новым брифом
6. Диагностика Barry Hott: низкий hook rate → чинить «Секунду 0» (картинка + первые слова);
   хороший hook + низкий hold → проблема в несоответствии обещания и боди, не в хуке
